# Конкуренты по запросу «фулфилмент» (Яндекс) — функции сайта и способ его изготовления

Собрано вживую через браузер: поисковая выдача Яндекса по запросу «фулфилмент» —
и реклама, и органика, — плюс два сайта, всплывших ранее (Yunu, Фулфилмент
Платформа, ATC C&L). По каждому сайту: что за компания, какие реальные функции
показаны на сайте, и — отдельным вопросом — **на чём технически сделан сам
сайт** (проверено через код страницы: `meta[generator]`, домены подключаемых
скриптов, фирменные метки конструкторов). Это НЕ про то, есть ли у компании
ИИ в продукте — это про то, слеплен ли сам сайт через ИИ-конструктор
(v0/Lovable/Framer AI и т.п.) или сделан руками/через обычный no-code
редактор.

## Как читать колонку «сайт сделан на»

Определялось по объективным техническим следам, не на глаз:

- **Tilda** — домены `tildacdn.com` в подключаемых скриптах. Это визуальный
  конструктор блоков для людей (drag-and-drop), не ИИ-генератор текста/кода.
- **1С-Битрикс** — строки `bitrix`/`bx_` в HTML. Классическая российская CMS,
  сайты на ней делают студии/веб-мастера вручную.
- **Самописный HTML + jQuery** — свои скрипты с домена самого сайта плюс
  `ajax.googleapis.com`/`cdnjs.cloudflare.com` для библиотек, никакого
  фреймворка сборки. Старый ручной сайт.
- **React + Vite (SPA)** — `div#root`, хэшированные бандлы `/assets/index-*.js`.
  Сам по себе этот стек не доказывает и не опровергает ИИ-генерацию — им
  пользуются и разработчики, и ИИ-кодогенераторы (Lovable/v0/Bolt тоже часто
  выдают ровно React+Vite). Вывод по такому сайту — через вторичные признаки
  (см. ниже).
- **Собственный no-code конструктор (Craftum)** — сайт сам является продуктом
  такого конструктора, CDN с поддомена самого бренда.

Прямых технических следов «сайт сгенерирован ИИ» (специфичных меток
Lovable/v0/Bolt/Framer AI, тегов вида `data-lovable`, характерных id) не
найдено ни на одном из проверенных сайтов. Там, где стек допускает такую
гипотезу (React+Vite, крайне шаблонная структура), это отмечено как
**предположение**, а не установленный факт.

## Сайты из выдачи

### 1. filmsib.ru — Фулфиллмент Центр (Новосибирск)

**Компания:** локальный 3PL-оператор. Склад рядом с сортировочными центрами
Wildberries/Ozon, работает по FBO/FBS.

**Функции на сайте:** заявка с расчётом КП, прямая видеотрансляция со склада
24/7 (аргумент доверия, не WMS-функция), фиксированный тариф от 20₽/ед.,
акция «первая 1000 единиц бесплатно», работа 7 дней в неделю. Личного
кабинета, трекинга заказов, API — нет.

**Сайт сделан на:** **Tilda** (`static.tildacdn.com`, `neo.tildacdn.com` в
скриптах). Обычный конструктор лендингов, собран вручную блоками, не ИИ.

### 2. tu-don.ru → aswms.ru — «Технологии учёта» / AS WMS (Ростов-на-Дону)

**Компания:** 1С-интегратор (20 штатных программистов, по их же описанию),
продаёт готовую WMS-надстройку **AS WMS** поверх 1С как услугу внедрения.

**Функции продукта AS WMS:** приём/отгрузка/перемещение через ордерную схему,
инвентаризация, учёт по характеристикам/партиям/срокам годности, реальная
интеграция с «Честный знак», KPI кладовщиков, адресное хранение, учёт
контейнеров, визуализация топологии склада. Есть облегчённая версия AS WMS
Lite (без адресного хранения). Это самый функционально близкий к Укладу
софтверный продукт из всей подборки после МПФИТ.

**Сайт tu-don.ru сделан на:** **1С-Битрикс** (`bitrix`, `bx_` в HTML;
собственный хост скриптов + счётчики Метрики и Топ Mail.ru). Классическая
студийная разработка.

**Сайт aswms.ru сделан на:** **Tilda** (та же CDN, что у filmsib.ru — похоже,
эту связку сайтов ведёт одна веб-студия через один и тот же инструмент).

### 3. sklad-pollar.ru — «Поллар» (Балашиха)

**Компания:** ответственное хранение и аренда складов класса А/В, Московская
область (Балашиха, Железнодорожный).

**Функции на сайте:** подробная прозрачная тарифная сетка (хранение от 35₽/
паллето-место, разгрузка/погрузка ручная и механизированная, паллетирование,
подготовка документов), сравнение «свой склад vs Поллар», форма расчёта за 15
минут, блог на 4 статьи, FAQ-аккордеон. Личного кабинета, трекинга, API — не
обнаружено, только заявка и звонок.

**Сайт сделан на:** **React + Vite (SPA)** — обнаружен `div#root` с реальным
деревом компонентов, хэшированные бандлы Vite (`/assets/index-*.js`), не
Tilda/Wix/Bitrix/WordPress (упоминание «wp-content» в HTML — это просто путь
к статичным картинкам блога, не признак самой платформы). Из всех проверенных
сайтов это единственный кастомно написанный SPA, а не собранный в no-code
конструкторе.

**Предположение (не факт) — вероятно сгенерирован через ИИ-конструктор
кода.** Основание: стек React+Vite без единого явного продуктового бренда
разработки — ровно то, что выдают инструменты вроде Lovable/v0/Bolt по
умолчанию; структура страницы предельно шаблонная и совпадает почти один в
один со «стандартным скелетом лендинга склада», который такие инструменты
генерируют по промпту (hero → ключевые метрики → карточки услуг → таблица
тарифов → 4 шага работы → сравнение «свой склад vs мы» → фотогалерея →
FAQ-аккордеон → карточки блога → CTA-форма); тексты гладкие, без опечаток и
без индивидуального голоса компании. Прямых технических меток
(`data-lovable`, специфичных id генератора) не найдено — так что это
основанная на структурных признаках гипотеза, а не подтверждённый факт.

### 4. yunu.ru — Yunu (ООО «ГК «МПКТ»)

**Компания:** фулфилмент-оператор со складами в Видном и Воронеже + **своя
внутренняя IT-команда, разрабатывающая WMS** (по их собственному тексту на
сайте).

**Функции:** личный кабинет с биллингом в реальном времени, аналитика продаж
по SKU, API для интеграций, явный шаговый онбординг (заявка → оферта →
настройка кабинета → приёмка → обработка заказов → оплата).

**Сайт сделан на:** **Tilda** + Roistat (коллтрекинг). Обычный конструктор
лендингов, ручная сборка.

### 5. ff-platform.ru — Фулфилмент Платформа

**Компания:** крупный 3PL (12 000 м², 130 сотрудников, 3000 клиентов),
работает с WB/Ozon/Яндекс.Маркет/AliExpress.

**Функции:** личный кабинет (остатки в реальном времени, заявки на отгрузку,
расчёт доставки, статусы, возвраты, брак), подробный прайс по каждой операции
без абонентки, работа с СДЭК/Boxberry/DPD/ПЭК/Деловые линии.

**Сайт сделан на:** **самописный HTML + jQuery** (`ajax.googleapis.com`,
`cdnjs.cloudflare.com`, собственный хост скриптов, без фреймворка сборки).
Судя по копирайту «© 2021» в подвале — старый ручной сайт, не менявшийся
годами, не ИИ-генерация.

### 6. atccl.ru/fulfilment — ATC Consulting & Logistics

**Компания:** международный логист (Китай/Турция/Владивосток/Москва, 20+ лет
на рынке), фулфилмент — одна из услуг, основной фокус на импорте и таможне.

**Функции:** склад «управляется WMS-системой по стандарту VDI 3601» (то есть
используют чужую/сертифицированную систему, не свою), работа по FBO,
подробный прайс на складские операции, отзывы клиентов, форма заявки.

**Сайт сделан на:** **1С-Битрикс** (`cdn-ru.bitrix24.ru`, `bitrix` в HTML) +
Calibri/Gudok (коллтрекинг). Студийная разработка, не ИИ.

### 7. craftum.com/blog/fulfilment — источник списка «ТОП-15»

Не конкурент Уклада, а статья-подборка, через которую были найдены три
компании выше. Сам сайт craftum.com — это конструктор сайтов (собственный
бренд, CDN `2.craftum.com`), статья написана как контент-маркетинг для
привлечения клиентов на сам конструктор.

## Итог

Среди всех проверенных сайтов **ни один не несёт прямых технических следов
ИИ-генерации** (нет специфичных меток Lovable/v0/Bolt/Framer AI). Реальная
картина по инструментам: три сайта на **Tilda** (filmsib, aswms, yunu, похоже
их ведёт одна и та же студия), два на **1С-Битрикс** (tu-don, atccl), один
**самописный HTML+jQuery** (ff-platform, старый), и один **React+Vite SPA**
(sklad-pollar) — единственный, где стек и шаблонность структуры делают
гипотезу «собран через ИИ-конструктор» правдоподобной, но не доказанной.

Практический вывод для Уклада: подавляющее большинство сайтов в этой нише —
типовые no-code лендинги от местных веб-студий, без какой-либо технологической
претензии на самом сайте. Даже у сайта с наиболее вероятными признаками
ИИ-генерации (sklad-pollar.ru) это касается только маркетингового лендинга,
а не самого продукта — WMS-функциональности за этим сайтом не обнаружено
вообще.
