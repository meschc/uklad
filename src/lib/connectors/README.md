# Подключения к внешним системам

WB, Ozon и Яндекс Маркет ходят через сервер: ключ селлера хранится там
шифрованным (`server/api/src/cabinet/connectors.js`, миграция 035), браузер
шлёт только номер подключения. Остальные системы — пока без серверной части. Разбор по сервисам, доступу и
препятствиям — `uklad-leads/integrations-chz-marketplaces-2026-10-21.md` в
файлах проекта.

## Обязательно для сервера (проверка безопасности)

1. Прокси не принимает произвольные method и path: белый список методов и
   шаблонов путей на каждую систему, остальное — 403.
2. `account` проверяется по сессии: подключение принадлежит компании
   пользователя, и роль имеет право на этот вызов.
3. Origin строго u-klad.ru, CORS без `*`, Allow-Credentials только своему
   домену. Адрес сервера в клиенте — только свой домен.
4. Ключи селлеров хранятся зашифрованными (ключ шифрования в env, не в
   базе), не попадают в журналы и ответы. Заголовки площадки в ответ не
   пропускаются.
5. Лимит частоты на пользователя и на подключение.
6. Токен ГИС МТ живёт только на сервере. Коды с криптохвостом — только на
   сервере, с коротким сроком хранения, без записи в журналы.

7. Подстановки в пути и теле (`{campaignId}`, `businessId`, `data.token`)
   сервер берёт только из записи подключения. Такие же значения из запроса
   браузера отбрасываются, иначе чужим `campaignId` можно попасть в чужой
   магазин тем же ключом.
8. Ответы площадок (в том числе gzip у МоегоСклада) распаковываются с
   пределом размера (50 МБ) и времени: «zip-бомба» или огромная выгрузка не
   должны положить сервер.

## Что осталось допилить

1. **Сервер** — сделан для WB, Ozon, Маркета (`POST /api/connectors/<system>/proxy`,
   белый список, шифрование, лимиты). Авито, Мегамаркет, МойСклад, ГИС МТ —
   добавить в `SYSTEMS` того же модуля со своими путями и заголовками.
2. **Транспорт** переключён: в сборке с сервером — `createServerTransport`.
   До переезда Авито, Мегамаркета, МоегоСклада и ЧЗ на сервер: старые ключи
   из `integrations` (браузер и снимок) вычистить и все площадки перевести на
   `connector_accounts`. После запуска — смена `CONNECTOR_SECRET_KEY` без
   повторного ввода ключей (перешифровка).
3. **Подпись для ГИС МТ**: реализовать `MarkSigner` через плагин КриптоПро
   в браузере пользователя (ключ селлера в Уклад не попадает).
4. **Экран интеграций**: для WB, Ozon, Маркета ключ уходит на сервер
   (`ServerConnections`), есть «Проверить связь». Дальше — загрузка заказов
   площадки в задания склада и выгрузка остатков.
5. **Связка номеров**: хранить `ExternalRef[]` в сторе (не забыть
   `partialize` и `sanitize`), заполнять при импорте товаров и при первом
   незнакомом заказе с площадки.
6. **Сверить с живыми кабинетами** пути и форму ответов (комментарии в
   адаптерах), добавить `marks.attach` по строке заказа (Ozon — экземпляры, Маркет —
   `identifiers`, Авито — `markings`) и заказы Мегамаркета по живому кабинету.
7. **Приёмка и сборка**: заменить `parseHonestSignMock` на `parseMarkingCode`,
   хранить код маркировки при экземпляре и коробе.
