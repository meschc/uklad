# Подключения к внешним системам

Каркас готов в браузере; чтобы подключения заработали, осталось сделать
серверную часть и переключить одну строку. Разбор по сервисам, доступу и
препятствиям — `uklad-leads/integrations-chz-marketplaces-2026-10-21.md` в
файлах проекта.

## Что уже есть

| Файл                | Что делает                                                                |
| ------------------- | ------------------------------------------------------------------------- |
| `types.ts`          | Общий контракт: заказ, остаток, этикетка, проверка кода, `Connector`      |
| `transport.ts`      | Порт наружу; `offlineTransport` до сервера, `createServerTransport` после |
| `identity.ts`       | Единый номер Уклада: связка товара с nmID, SKU, артикулом, баркодом, GTIN |
| `wildberries.ts`    | FBS: новые заказы, стикеры, остатки, коды маркировки в заказ              |
| `ozon.ts`           | FBS: отправления, этикетки, остатки                                       |
| `honestSign.ts`     | ГИС МТ: вход по подписи пользователя, проверка кодов                      |
| `../markingCode.ts` | Разбор кода DataMatrix: GTIN, серийник, криптохвост, проверка GTIN        |

## Что осталось допилить

1. **Сервер**: `POST /api/connectors/<system>/proxy` — принимает `ConnectorRequest`,
   достаёт ключ подключения `account` из зашифрованного хранилища, подставляет
   базовый адрес и заголовки площадки, соблюдает лимиты (очередь на
   систему), возвращает JSON площадки как есть. Бинарные ответы (PDF Ozon) —
   в поле `file` base64. Для ГИС МТ хранит токен после `simpleSignIn`.
2. **Переключить** `transport` в `index.ts` на `createServerTransport(адрес)`.
3. **Подпись для ГИС МТ**: реализовать `MarkSigner` через плагин КриптоПро
   в браузере пользователя (ключ селлера в Уклад не попадает).
4. **Экран интеграций**: при сохранении ключ уходит на сервер, а не в
   localStorage; в браузере остаётся только номер подключения.
5. **Связка номеров**: хранить `ExternalRef[]` в сторе (не забыть
   `partialize` и `sanitize`), заполнять при импорте товаров и при первом
   незнакомом заказе с площадки.
6. **Сверить с живыми кабинетами** пути и форму ответов (комментарии в
   адаптерах), добавить Ozon `marks.attach` (экземпляры), Яндекс Маркет и
   МойСклад по тому же образцу.
7. **Приёмка и сборка**: заменить `parseHonestSignMock` на `parseMarkingCode`,
   хранить код маркировки при экземпляре и коробе.
