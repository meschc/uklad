# Codemap · UI (`src/components`)

`App.tsx` — роутер по `appView` из стора. `?heatmap=1` в URL открывает только
тепловую карту (отдельное окно, читает тот же localStorage). Каждый экран
обёрнут `ErrorBoundary` с ключом по виду: падение одного экрана не роняет
приложение и не мешает уйти в соседний пункт меню (`components/ErrorBoundary`).

## nav/ — боковой рельс

```
SideNav          двухуровневый рельс (п.10). Наверху логотип — единственный
                 выход в кабинет: под курсором знак меняется на стрелку и
                 проявляется подпись «На главную», отдельного пункта в рельсе
                 нет. Дальше: План склада · [Работа: Приёмка · Задания ·
                 Сборка] · [Печать: Наклейки · Документы] · [Склад: О складе ·
                 Персонал · Интеграции] · Аналитика · Что это?
                 («Что это?» — отдельным пунктом внизу: справочник, к которому
                 обращаются по случаю, ему нельзя стоить двух кликов.)
                 Группа раскрывается подменю вбок, счётчик заявок суммируется
                 на группе. У продавца набор плоский: Остатки и заявки · План ·
                 О складе · Персонал, всё только на чтение.
                 navFor(role) разворачивает группы в плоский список — им же
                 App.tsx отсекает экраны, недоступные роли. Экраны уровня
                 аккаунта в этот список НЕ входят и проверяются отдельно
RoleSwitch       переключатель «Кладовщик / Продавец» — живёт на Главной
```

## Соглашения UI

- Строки — только через `useT()`; ключ добавляется сразу в ru **и** en.
- Иконки — `lucide-react`, размер `size-3.5` / `size-4`. Толщина штриха
  утоньшена глобально в `index.css` (`svg.lucide { stroke-width: 1.6 }`) —
  штатные 2 при кегле подписи 10–13 px выглядели жирнее текста.
- Диалог: `fixed inset-0 z-50` + backdrop `animate-fade-in` + карточка
  `animate-scale-in rounded-xl border border-border bg-card`.
- Предупреждение о потере данных — `hazard-stripes` + amber, как в
  `GoodsConflictDialog`.
- Успех — emerald, ошибка — destructive, расхождение — amber.
- В мастере сначала переход на следующий шаг, потом сообщение в строку
  состояния. Смена шага гасит подсветку скана, а React склеивает обновления
  одного обработчика — при обратном порядке успех молча пропадает и экран
  отзывается только на ошибки (`ReceivingScreen`).
