# Дизайн-система «Уклада» — спецификация для Figma

Источник истины — код: `src/index.css` (токены-переменные), `tailwind.config.js`
(шкалы) и `src/components/ui/*` (примитивы). Этот документ + `design-tokens.json`
нужны, чтобы собрать в Figma библиотеку, которая совпадает с кодом один в один,
и дальше держать их синхронными.

Система одна на витрину и кабинет ([ADR 0007](../adr/0007-odna-dizajn-sistema.md)).
Для тех, кто код не открывает, она же выложена артефактом:
https://claude.ai/artifact/Tadqydujk1gJrKcysRePzm.

## Как перенести токены в Figma

1. Плагин **Tokens Studio for Figma** → Import → `docs/design/design-tokens.json`.
2. Наборы: `color/light`, `color/dark` — два режима (Figma Variables → Modes),
   общие для витрины и кабинета; `brand` (цвет знака, от темы не зависит),
   `radius`, `radiusSite`, `size`, `spacing`, `typography`.
3. В Figma создать Variable Collection «Уклад» с режимами **Light / Dark** —
   имена переменных совпадают с CSS: `background`, `foreground`, `primary`,
   `muted`, `border`, `ring`, `destructive`, `m-section`, `canvas-bg` и т. д.
4. После правок в `index.css` перегенерировать файл: `npm run tokens`. Скрипт
   пересобирает только блок `color`; `brand`, `radius`, `radiusSite`, `size`,
   `spacing` и `typography` ведутся руками — правя шкалу в коде, поправьте и их.

## Семантика цвета

Цвета названы по роли, а не по оттенку — это уже семантические токены:

| Токен                                           | Роль                                         |
| ----------------------------------------------- | -------------------------------------------- |
| `background` / `foreground`                     | фон страницы и основной текст                |
| `card` / `card-foreground`                      | поверхность карточки, панели, диалога        |
| `popover`                                       | всплывающие слои (меню, тултип)              |
| `primary`                                       | основное действие, активный пункт, выделение |
| `secondary`                                     | второстепенная заливка                       |
| `muted` / `muted-foreground`                    | приглушённый фон и подписи                   |
| `accent`                                        | ховер-подсветка строк и пунктов              |
| `destructive`                                   | удаление, ошибка, «не влезает»               |
| `border` / `input` / `ring`                     | контуры, поля, фокус                         |
| `canvas-bg`, `grid-minor`, `grid-major`         | холст плана и сетка                          |
| `floor`, `floor-edge`                           | плита пола (проход = пол)                    |
| `m-section`, `m-stairs`, `m-elevator` (+ `-fg`) | типы модулей плана                           |

Статусы: успех — `success`, предупреждение и расхождение — `warning`,
ошибка — `destructive`. Один токен на роль, в тёмной теме он светлеет сам:
`text-warning`, `bg-warning/10…15`, `border-warning/40`. Парами `amber-600` +
`dark:amber-400` больше не пишется. В кабинете ещё встречается `emerald-*` в
роли успеха; новое так не пишется — только `success`.

Своей палитры у витрины нет: она берёт те же роли, и акцент текста на ней —
тот же `primary`. **Знак** (логотип из клеток, `components/brand/UkladLogo.tsx`)
записан постоянным `#2563EB` (токен `brand.mark`), а не токеном темы, потому
что фавикон и превью для соцсетей живут вне сборки и тему не видят.

## Шрифт

Одна гарнитура на витрину и кабинет — **Medeo** (с 31 октября 2026, до неё
Geist). Medeo Sans набирает текст и заголовки, Medeo Mono — адреса ячеек,
коды и артикулы (`font-mono`). Обе переменные: вес 100..900, оптический
размер 14..32. Ступени веса — 400 текст, 500 кнопки и подписи, 550
заголовки (`font-heading`). Лицензия SIL OFL 1.1, файлы подрезаны до
кириллицы и латиницы и лежат в `public/fonts` (справка — `CREDITS.md`).
В Figma — тот же Medeo с prtner.ai/font, токены `fontFamily.sans` и
`fontFamily.mono` в `design-tokens.json`.

## Шкала скруглений

Шкал две, и это не разнобой, а разные задачи. На рабочем экране одновременно
живут десятки контролов, и крупный радиус там читается как игрушечность. На
витрине блоков на экране три, и радиус — часть того, что отличает свежую
страницу от страницы пятилетней давности.

### Приложение — `src/index.css`, `tailwind.config.js`

`--radius: 10px` — база, радиус панели. Ступени: `DEFAULT 4` · `sm 6` ·
`md 8` · `lg 10` · `xl 12` · `2xl 16` · `full`.

Правило вложения: **внутренний радиус = внешний − отступ**. Шаг 2px равен
типовому отступу вложения (`p-0.5`), поэтому правило выполняется сдвигом на
ступень вниз: `xl→lg→md→sm→DEFAULT`. Контейнер `rounded-lg` (10) с `p-0.5` (2)
→ вложенный элемент `rounded-md` (8). Между `xl` (12) и `2xl` (16) шаг 4px:
`2xl` стоит снаружи и ни во что не вкладывается.

### Витрина — `src/site/site.css`

Скругление — это и есть характер витрины, единственное, что она объявляет
поверх общей системы (вместе с ритмом длинной страницы). Файл импортируется
только из `src/site/main.tsx`, в бандл `/app/` не попадает и на рабочий экран
не влияет по построению.

Шкалы у витрины больше нет: у всех поверхностей один радиус `--r: 2px`, а
форма ушла с поверхностей на действия.

| Класс                                               | Значение        | Что это                                              |
| --------------------------------------------------- | --------------- | ---------------------------------------------------- |
| `r-slab`, `r-window`, `r-inset`, `r-tile`, `r-chip` | **2px** (`--r`) | все поверхности: плита, окно, вставка, плашка, лист  |
| `rounded-full`                                      | —               | всё, что высотой в одну строку и на что можно нажать |

Пять имён оставлены как метки уровня в разметке: значение у них общее и
меняется одной строкой в `site.css`.

Второе правило: **строчный контрол — пилюля**. Кнопка, поле, `select`, чип
фильтра, бейдж, переключатель — всё, что высотой в одну строку. Кончается
правило там же, где кончается строка: карточка-переключатель с заголовком и
абзацем внутри остаётся окном. Пилюля высотой в четыре строки — не пилюля,
а овал.

## Высоты контролов (главное правило)

Одна строка интерфейса — одна высота. Только три ступени:

| Ступень | Высота   | Кто использует                                                                           |
| ------- | -------- | ---------------------------------------------------------------------------------------- |
| `sm`    | **32px** | `Button size="sm"`, `Input` по умолчанию, `Segmented size="sm"`, иконка-кнопка `icon-sm` |
| `md`    | **36px** | `Button` (default), `Segmented size="md"`, поля форм с `className="h-9"`, `<select>`     |
| `lg`    | **40px** | `Button size="lg"`                                                                       |
| особое  | **44px** | `ScanField` — под палец и сканер                                                         |

Если в одной полке стоят кнопка, поле и переключатель — они обязаны быть одной
ступени. В Figma это варианты компонента `Control / Size = sm | md | lg`.

## Компоненты и их варианты

### Button (`src/components/ui/button.tsx`)

- **variant**: `default` · `destructive` · `outline` · `secondary` · `ghost` · `link` ·
  `inverse` (белая на синей заливке) · `inverse-outline` (белая обводка на синей)
- **size**: `sm (32)` · `default (36)` · `lg (40)` · `icon (36×36)` · `icon-sm (32×32)`
- **shape**: `default` (радиус по размеру) · `pill` (`rounded-full`) — форма
  витрины. Пилюля меняет только угол: высоты и цвета те же, что в кабинете
- **состояния**: rest · hover · focus-visible (ring 2px `ring` + offset 1px) ·
  active (scale 0.97) · disabled (opacity 0.5, без событий)
- иконка внутри — 16px, зазор 8px, скругление по размеру (`md` для sm)

### Кнопки витрины

Своих кнопок у витрины нет — только `Button` с `shape="pill"`. Класс
`.wh-btn` (48 px, свои цвета) удалён 10.11.2026, все его места переведены:

- синяя заливка → `default`, светло-серая → `secondary`;
- на синем первом экране и в выбранном тарифе → `inverse` и `inverse-outline`;

- обычное действие на странице — `size="lg"` (40), тон по смыслу: заливка
  (`default`) для главного, `outline` рядом с ней, `ghost` для служебного;
- служебное в плотной строке (фильтры в каталоге) — `size="sm"` (32);
- кнопка-иконка (отправить в чате) — `size="icon"` (36);
- **главный призыв со стрелкой** («Подобрать склад», «Стать оператором») —
  `CtaLink` (`src/site/components/CtaLink.tsx`): та же основная кнопка `lg`
  пилюлей, ссылкой `<a>` и со стрелкой `→`, которая на ховере сдвигается
  вправо. Отдельной формы «пилюля в пилюле» (48 px, тёмная заливка) больше
  нет — её высоты не было в ряду 32 / 36 / 40.

### Текст без полутонов

Второстепенный текст — `text-muted-foreground` целиком, без `/40…/70`;
основной — `text-foreground` без прозрачности. Полупрозрачные заливки ролей
(`bg-success/12`, `bg-warning/10`) разрешены, `opacity-*` — только для
появления, исчезновения и `disabled`.

### Поле скана (`fulfillment/ScanField.tsx`)

Высота 44, моно, иконка скана слева, рамка по статусу (успех / ошибка).
Русские буквы сами меняются на латинские с тех же клавиш
(`fixKeyboardLayout`, `lib/emailTyping.ts`): браузер не переключает
раскладку системы, а коды склада — только латиница.

### Eyebrow (`ui/eyebrow.ts`)

Надзаголовок — классы, а не компонент: им бывает `span`, `dt`, `th`, `p`.

- **size**: `xs` (10) · `sm` (12, по умолчанию)
- **weight**: `normal` · `medium` · `semibold` (по умолчанию)
- **tone**: `muted` (по умолчанию — подпись поля) · `current` (цвет
  окружения) · `primary` — рубрика над крупным заголовком секции на витрине
  («ТАРИФЫ», «СЕЛЛЕРУ»)
- машинная подпись над «404» и экраном сбоя — тот же надзаголовок с
  `className: "font-mono"`

### Input (`ui/input.tsx`)

- высота 32 (по умолчанию) или 36 (`h-9`), радиус `md`, `border: input`,
  тень `shadow-sm`
- состояния: rest · focus (ring 2px) · disabled · **error** (`border-destructive`
  - подпись 12px `destructive` под полем). Ошибка в фокусе — одна красная
    обводка, без синей; с первым набранным символом красное снимается до ухода
    из поля (`data-typing`, `index.css`)
- варианты содержимого: текст · моно (адрес/артикул) · числовой (табличные цифры,
  спиннеры скрыты)

### Segmented (`ui/segmented.tsx`)

Единственный вид «кнопок-табов»: роль, режим просмотра, фильтр, тема, язык.

- контейнер: `bg-muted`, радиус `lg`, `p-0.5`, высота 32/36
- сегмент: активный — `bg-background` + `shadow-sm`, неактивный —
  `muted-foreground`, ховер → `foreground`
- **grow** — сегменты делят ширину поровну (контрол во всю строку)

### Field / Labeled

Подпись — `typography.label` (`ui/eyebrow`: 12px, 600, uppercase, трекинг
0.025em, `muted-foreground`), зазор 6px до контрола, ошибка — 12px
`destructive` под контролом. Готовый компонент — `ui/field`: `Field` (подпись,
контрол, подсказка или ошибка; сам ставит `aria-invalid` и `aria-describedby`),
`FieldError` (ошибка под полем) и `FormError` (отказ на всю форму у кнопки
отправки). Ошибка всегда со значком `CircleAlert`, не только цветом. Своё
«`text-xs text-destructive`» линтер не пропускает.

### Card / Panel

`bg-card`, `border`, радиус `xl` (12), тень `shadow-sm`; заголовок секции —
`titleSection` (14/600). Плавающие панели редактора — радиус `xl`, `shadow-lg`.

### Dialog

Окон по центру нет: `DialogShell` — панель справа на всю высоту.
Backdrop `black/40` + `backdrop-blur-[1px]`, панель шириной по `size`
(`max-w-sm`…`max-w-3xl`), **без скруглений**, рамка только слева, `shadow-2xl`;
шапка и подвал разделены `border`, подвал — `bg-muted/30`. Образец — «Сообщить о
проблеме». Своих панелей не пишем: любая панель справа — `DialogShell` +
`DialogHeader`/`DialogFooter`. Анимации: `animate-fade-in` (backdrop),
`animate-slide-in-right` (панель, 320 мс).

### Движение

Три длительности на весь кабинет (`tailwind.config.js`): `duration-fast` 120 мс —
отклик на нажатие и наведение; `duration-base` 200 мс — раскрытие, смена вкладки,
появление; `duration-slow` 320 мс — панель справа и смена числа. Кривая одна —
`ease-out-soft`. Готовые анимации: `animate-expand-in` (раскрытый блок),
`animate-tab-in` (содержимое вкладки), `animate-slide-in-right` (панель).
Числа, которые меняются на глазах (аналитика, счётчики), — `ui/animated-number`:
добегают до нового значения, первый показ — сразу итог. При «уменьшить
движение» в системе всё движение выключается. На рабочем месте движение только
там, где меняется состояние: сканер не ждёт анимацию.

### Пределы чисел

Числовое поле без предела не проходит линтер. Пределы по смыслу — в
`src/lib/numberLimits.ts` (`count` до 99 999 штук, `small` до 9 999 — доки,
камеры, места; `year` 1900…текущий; `area`, `size`, `kg`, `money`, `percent`).
`type="number"` получает `max`, текстовое числовое поле — `maxLength`
(`digitsFor`), телефон — `maxLength={PHONE_MAX_LENGTH}` (20 знаков, 15 цифр).
В браузере `installNumberLimits` прижимает набранное к `max` сразу, а не при
отправке формы.

### Рамки

Рамка — только у самой внешней поверхности (карточка, поле ввода, панель).
Внутри карточки блоки разделяются отступом и заголовком, а не второй рамкой.

### Alert (единый паттерн предупреждения)

Шапка со штриховкой `hazard-stripes` (полосы прижаты к правому краю и гаснут к
центру) + `bg-warning/10`, иконка `AlertTriangle`. Два **равноценных** действия
рядом — «Перепроверить» / «Записать как есть»: интерфейс не решает за человека.
Ошибка-факт (например «разместить не удалось») — тот же паттерн + кнопка
«Понятно».

### Toast, Badge, Table

- Toast — см. «Уведомления» ниже
- Badge/чип: 12px (`text-xs`), в плотных местах (таблица, строка списка) 10px
  (`text-2xs`); кегля 11px в шкале нет. Радиус `sm`/`DEFAULT`, `bg-muted` либо `bg-primary/10 text-primary`
- Таблица: строка 32–36px, шапка `bg-muted/50` 12px, ховер строки `accent/40`,
  выбранная строка `primary/5`, моно-колонки для артикула, адреса и штрихкода

## Уведомления и ошибки

**Что считать ошибкой** — только `src/lib/validate.ts`: почта (зона буквами,
одна азбука), имя (без цифр), должность и названия (без номера-простыни),
телефон (российский — 11 цифр, иностранный — с «+»), ИНН, КПП, ОГРН с
контрольной цифрой, ссылка. Своих регулярок в формах не заводим; почту на
сервере проверяет `server/api/src/validate.js` по тем же примерам
(`validate.cases.json`). Ошибка показывается после ухода из поля или первой
попытки сохранить; пока она есть, сохранить нельзя. Удачное сохранение
формы — тост `success` с тем, что сохранено.

Одно правило на кабинет, рабочее место и админку (Кирилл 13 ноя: «если что-то
в форме или поле ввода не так, то рядом с полем должно быть отображение
ошибки»).

| Что случилось                            | Где показываем                               | Компонент                      |
| ---------------------------------------- | -------------------------------------------- | ------------------------------ |
| Неверно заполнено поле                   | под этим полем, рамка поля красная           | `Field error=…` / `FieldError` |
| Сервер не принял форму                   | у кнопки отправки, форма не закрывается      | `FormError`                    |
| Результат скана на рабочем месте         | в самом поле скана и заливкой (`ScanBanner`) | —                              |
| Итог действия вне формы, фоновое событие | уведомление справа внизу                     | `notify(tone, key, …)`         |

Ошибку поля уведомлением не показываем: оно уходит, стоит далеко от поля и не
говорит, что править.

**Уведомление** (`lib/notice`, `components/Toaster`, вид — `ui/toast`):

- **тон обязателен** в каждом вызове: `success` — сделано, что просили;
  `info` — событие не от действия человека (сообщение в чате, режим чтения);
  `warning` — сделано не всё, ничего не сломано; `error` — отказ. Раньше тон по
  умолчанию был «успех», и отказ показывался зелёной галочкой;
- поверхность всегда `popover` (в тёмной теме тёмная, в светлой светлая), тон —
  значком: `CheckCircle2` / `Info` / `TriangleAlert` / `CircleAlert`;
- место: справа внизу, на телефоне во всю ширину над нижней панелью;
- стопка до трёх, свежее снизу; то же сообщение повторно не копится, а
  получает «×2»;
- сколько висит: успех и событие 4 с (длинный текст дольше), предупреждение
  7 с, ошибка 10 с, отменяемое действие ровно 8 с; наведение и фокус ставят
  паузу, крестик закрывает сразу;
- ошибка читается экранной читалкой сразу (`role="alert"`), остальное —
  вежливо (`role="status"`).

В админке скриптов нет (CSP): уведомление после действия передаётся кодом в
короткой куке (`FLASH` в `views/base.js`), уходит само на CSS, наведение ставит
паузу.

## Опасные действия

Класс опасности — как переспросить; кому можно — решает роль
(`src/lib/permModules.ts`). Источник — `src/lib/actionRisk.ts`.

| Класс          | Как ведёт себя                                                     | Примеры                                                       |
| -------------- | ------------------------------------------------------------------ | ------------------------------------------------------------- |
| `safe`         | сразу, без следа                                                   | открыть, отфильтровать, напечатать, скопировать               |
| `undoable`     | сразу, в тосте 8 с «Отменить» (`notify("success", key, { undo })`) | удалить партнёра, убрать свою услугу, удалить реплику чата    |
| `confirm`      | панель справа с тем, что изменится, кнопка `destructive`           | провести приёмку, закрыть рейс, выставить счёт, списать товар |
| `irreversible` | панель справа, подтверждение вводом названия, только руководитель  | удалить компанию, отправить документ наружу                   |

«Вы уверены?» на каждое удаление не спрашиваем: так привыкают жать «да» не
читая. Обратимое делаем сразу и даём отменить, необратимое переспрашиваем
по-настоящему.

## Иконки

`lucide-react`, штрих 2px. Размеры: 14px (в тексте и мелких кнопках), 16px
(кнопки и поля), 18–20px (навигация и пустые состояния). В Figma — библиотека
Lucide, тот же набор имён.

## Тёмная тема

Не отдельная библиотека, а второй режим переменных: любой компонент собран на
семантических токенах и переключается вместе с коллекцией.

## Что синхронизировать при правках

Каждая строка ниже — это и правка артефакта дизайн-системы, в той же задаче.
Сменились шрифт или марка — тоже: артефакт показывает их наравне с токенами.

| Изменилось в коде                       | Что править в Figma                                                        |
| --------------------------------------- | -------------------------------------------------------------------------- |
| `--*` в `index.css`                     | перегенерировать токены (`npm run tokens`) и переимпортировать             |
| высоты в `button.tsx` / `segmented.tsx` | варианты `Size` у соответствующих компонентов                              |
| новый примитив в `ui/`                  | новый компонент + запись в этот файл                                       |
| знак (`brand/UkladLogo.tsx`)            | `brand.mark` в токенах, `public/favicon.*`, `og.*`, `apple-touch-icon.png` |
