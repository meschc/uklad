# История изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), нумерация —
[Semantic Versioning](https://semver.org/lang/ru/). Пока продукт не выпущен,
старшая цифра остаётся нулевой: ломающие изменения ещё нормальны.

Сюда попадает то, что заметно снаружи — человеку на витрине или кладовщику в
кабинете. Перекладки файлов, правки формата и обновления зависимостей — нет:
для них есть история коммитов.

## [Не выпущено]

### Добавлено

- **Витрина складов** целиком: каталог с фильтрами и картой, карточка склада,
  расчёт стоимости хранения, заявка складу, страница для селлеров.
- **Дорожная карта** (`/roadmap/`) — публичная страница со всем, что сделано,
  что пишется сейчас и что запланировано: доска по стадиям с отбором по
  направлению, крупные этапы с двухцветной полосой прогресса и журнал выпусков,
  повторяющий этот файл. Ни голосов, ни дат у отдельных пунктов: голосовать
  некому, а точной даты выхода у строки нет — есть выпуск и ориентир по
  кварталу. Правдивость данных держат тесты: версия обязана существовать в
  журнале, квартал стоит только у начатого и запланированного.
- **Правовые страницы** (152-ФЗ, 149-ФЗ, закон о защите прав потребителей):
  политика обработки персональных данных, пользовательское соглашение, оферта,
  согласия под формами и выбор cookie.
- **Английская версия сайта** — второй язык витрины со своими адресами,
  `hreflang` и переключателем. Правовые документы остаются русскими: силу имеет
  тот текст, который подан на русском.
- **Предрендер витрины** (`scripts/prerender.mjs` + `src/site/entry-server.tsx`):
  156 страниц готовой разметки и карта сайта на 78 адресов — чтобы поисковик и
  человек без JavaScript видели содержимое, а не пустой контейнер.
- **Слой данных** `src/lib/data/` — репозитории поверх `localStorage` с общим
  конвертом `Result<T>`. Шов, по которому подключается будущий бэкенд.
- **Компонентные тесты** в jsdom: галочки согласий, заявка складу, категории
  товаров, порядок шагов приёмки.
- **Оснастка**: ESLint 9 (flat config), Prettier, husky + lint-staged,
  GitHub Actions (формат, линтер, типы, тесты, сборка, сквозные тесты),
  `LICENSE`, `CONTRIBUTING.md`, этот файл, `docs/ARCHITECTURE.md`, `docs/adr/`.

### Изменено

- **Лендинг** пересобран: крупные плиты со скруглениями, один источник света,
  вложенные углы. Текст сокращён, пиксельный шрифт убран.
- **Словарь** разбит по доменам (`src/lib/i18n/`), английская половина стала
  `Record<MsgKey, string>` — пропущенный перевод теперь не собирается.
- **Крупные экраны** разрезаны на папки рядом с собой: `editor/canvas/`,
  `editor/inspector/`, `fulfillment/receiving/`. В проекте не осталось файлов
  длиннее 800 строк.
- **Проверенные склады** — только те, кого проверил «Уклад»; знак партнёра в
  интеграциях рисуется монограммой, логотипы стали круглыми.

### Исправлено

- **Приёмка молчала в ответ на удачу.** Строка состояния показывала только
  ошибки: успех писался перед сменой шага, а смена шага гасила строку — React
  склеивал оба обновления в одно. Теперь сначала переход, потом сообщение.
- **Поля склада не пересоздавались при смене склада** — в форме оставались
  данные предыдущего (ключ по складу на экранах паспорта и персонала).
